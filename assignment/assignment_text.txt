EDXSO AI Engineer Intern – Assignment 1
Automated Micro-Influencer Outreach System
Objective
Build an automated system that discovers relevant micro-influencers, filters and
classifies them based on predefined criteria, enriches their profiles with useful
information, and generates personalized collaboration outreach messages.
The system should demonstrate your ability to work with APIs, web scraping/data
extraction, data processing, automation, AI/LLM-based personalization, and
workflow design.
1. Influencer Discovery
Identify micro-influencers from a chosen niche such as:
● Fitness
● Fintech
● Beauty
● Fashion
● Crypto
● Parenting
● Gaming
● Lifestyle
● Technology
You may use:
● Instagram
● YouTube
● TikTok
● Hashtag searches
● Public influencer directories
● UGC marketplaces such as Collabstr, Aspire, or Grin
● Social media scraping/data extraction tools
● Creator newsletters and creator-spotlight pages

Definition
A micro-influencer should generally have 5,000–100,000 followers or demonstrate
equivalent audience engagement.
Requirement
Your system should fetch at least 50 influencers for the test run.
2. Filtering & Classification
Build logic to automatically filter and classify the discovered influencers.
Your system should consider:
● Category / niche
● Audience demographics
● Geography, if available
● Social media platform
● Follower count
● Engagement rate
● Brand-fit criteria
● Content relevance
Minimum Requirement
Implement at least one complete filtering category.
Example: Fashion & Beauty influencers.
The final output should clearly identify which influencers passed or failed the filtering
criteria and why.

4. Message Personalization
The system should automatically generate two types of personalized outreach
messages for each qualified influencer.
A. Email Collaboration Pitch
Length: 60–90 words
The email should reference relevant personalization signals such as:
● Influencer's niche
● Content tone/style
● Recent content
● Relevant audience
● Proposed collaboration
● Value proposition
Possible collaboration angles include:
● Sponsorship
● Affiliate campaign
● UGC content creation
● Brand ambassador program
● Paid product placement
● Barter collaboration
B. Instagram DM
Length: 15–30 words
The DM should be short, natural, and personalized based on the influencer's content
and niche.
Example Personalization
Instead of:
"Hi, we would like to collaborate with you."
The system should generate something closer to:

"Hi Sarah, loved your recent skincare routine content. Your
beauty-focused audience looks like a great fit for our upcoming UGC
campaign."
The system should generate these messages dynamically rather than using one
fixed template for every influencer.
5. Sending Layer
Build a sending layer that demonstrates how the generated outreach would be
delivered.
You may implement this using:
● Gmail API
● SMTP
● Email automation tools
● Instagram/Meta APIs where permitted
● n8n
● Make
● Zapier
● Another appropriate automation workflow
Requirements
The sending layer should:
1. Select influencers with a valid contact email.
2. Retrieve their personalized email message.
3. Send or simulate sending the email.
4. Record the sending status.
5. Prevent duplicate outreach.
6. Maintain a basic outreach log.
For Instagram DMs, if direct automated sending is not technically or legally available
through the chosen API, do not bypass platform restrictions. Instead,
demonstrate the generated DM and create a simulated/manual sending workflow.
